🔍 1. Code Review & Peer Feedback (90 min)

Upplägg:

Studenterna sitter i par eller små grupper (3–4 personer).

De visar upp sin lösning på minst en av övningarna (från lektion 1–2).

Fokus: hur de tänkte, hur de löste det, vad de hade kunnat göra annorlunda.

Använd gärna en enkel feedbackmall:
✅ Fungerar?
✅ Ren kod?
✅ Kreativa lösningar?
🛠 Vad hade kunnat förbättras?

Tips till dig som lärare:
När du går runt i grupperna – prioritera att:
Be studenterna förklara sin kod högt.
Ställ frågor som: "Varför valde du att göra så här?" eller "Vad skulle hända om...?"

Här kommer förslag på ämnen som bör förstärkas eller inte hunnits med:

✅ Persistent data (om det ej hunnits med tydligt)

Kort förklaring:
"Persistent betyder att datan finns kvar även efter att vi stänger av servern. NeDB sparar till fil, t.ex. books.db, vilket gör datan persistent. I minnet skulle allt försvinna vid omstart."

Visa gärna skillnaden i kod:
// In-memory
const db = new Datastore(); 

// Persistent
const db = new Datastore({ filename: "books.db", autoload: true });

💡 2. Repetition & Code-Along: MongoDB Atlas + Mongoose (60 min)
🎤 Teoretisk bakgrund (kort)
Vad är en molndatabas? Varför MongoDB Atlas?

Mongoose = bibliotek som hjälper oss strukturera MongoDB-data i Node.js.

Skillnad mellan NeDB och MongoDB + Mongoose.

🛠️ Skapa gratisdatabas på MongoDB Atlas:
Gå till: https://www.mongodb.com/cloud/atlas/register

Skapa ett gratiskonto och välj Shared Cluster (Free Tier)

Skapa en ny databas med:

Cluster name: ClusterFolkan (valfritt)

Database name: booksdb

Collection: books

Skapa en användare under Database Access (manduslindstrom)

Under Network Access, tillåt IP-adresser: "Allow Access From Anywhere (0.0.0.0/0)"

Kopiera connection string från Connect > Drivers > Node.js

Exempel (din sträng kommer skilja sig):

MONGODB_URI=mongodb+srv://manduslindstrom:DIN-LÖSENORD@clusterfolkan.mongodb.net/booksdb?retryWrites=true&w=majority

🎤 Talarmanus att använda under code-alongen:
"Vi börjar med att installera mongoose – ett bibliotek som gör det enklare att jobba med MongoDB i Node."

"MongoDB lagrar data i dokument, men mongoose tvingar oss att skapa en struktur – det vi kallar ett schema. Det är lite som TypeScript för databasen."

"Vi ansluter till vår molndatabas med hjälp av en connection string – den måste alltid vara hemlig i produktion, men vi använder den här tillfälligt."

"Varje route vi bygger är en CRUD-operation. Koden är snarlik NeDB – men skillnaden är att mongoose jobbar mer med await/async och har bättre felhantering."

"För att spara en bok skapar vi en ny instans av modellen (new Book(req.body)), och sedan .save()."

"I GET-routes använder vi Book.find() och Book.findById() – superenkelt!"

"Uppdatering görs med findByIdAndUpdate, och vi skickar { new: true } för att få tillbaka den uppdaterade boken."

"Delete använder findByIdAndDelete – fungerar som förväntat."
